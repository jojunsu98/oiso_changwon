# 오이소창원 Lite 발표 대본

> 권장 발표 시간: 4~5분  
> 발표자료: [`07-presentation-slides.md`](./07-presentation-slides.md)

## 슬라이드 1. 제목

안녕하세요. 창원 전입 청년의 첫 180일을 돕는 AI 정착 코디네이터, **오이소창원 Lite**를 소개하겠습니다. 이 프로젝트는 기존 오이소창원의 콘셉트와 검증 데이터를 유지하면서, 코디세이 개인 미션의 기술 요구사항에 맞게 다시 구현한 웹서비스입니다.

## 슬라이드 2. 문제와 타겟

창원으로 이사 온 청년은 주거, 취업, 교통, 복지 정보를 여러 기관에서 따로 찾아야 합니다. 정책을 발견해도 자신의 나이, 전입일, 재직 상태와 맞는지 판단하기 어렵고 신청 시점을 놓치기 쉽습니다. 주요 타겟은 창원으로 전입했거나 전입을 준비하는 청년입니다.

## 슬라이드 3. 기존 서비스에서 Lite로

기존 오이소창원은 Streamlit 기반 팀 프로젝트였습니다. 이번 개인 미션에서는 서비스 목적과 브랜드, 정책 데이터를 그대로 유지하되, 프론트엔드를 순수 HTML, CSS, JavaScript로 만들고 백엔드는 Vercel Python Functions로 분리했습니다. 즉, 새 아이디어를 만든 것이 아니라 같은 서비스를 과제 규격에 맞춰 재구현했습니다.

## 슬라이드 4. 서비스 구성

웹페이지는 홈, 서비스 소개, 맞춤 혜택, 생활 안내, AI 코디네이터, 안내의 여섯 섹션으로 구성했습니다. 핵심 흐름은 **내 조건 입력, 정책 판정, 일정과 다음 행동, AI 안내**입니다. 정책 자격은 규칙으로 비교하고 AI는 검증된 자료 안에서 설명하도록 역할을 구분했습니다.

## 슬라이드 5. 맞춤 혜택 판정

사용자가 나이, 전입일, 직업, 창원 사업장 재직 여부, 전입 전 거주 기간, 차량 여부를 입력하면 정책 24건을 판정합니다. 결과는 해당 가능, 조건부 해당 가능, 직접 확인, 해당 없음의 네 단계로 구분합니다. AI는 이 판정 결과에서 우선 확인할 정책과 다음 행동을 짧은 정착 브리핑으로 설명합니다.

## 슬라이드 6. AI 코디네이터

AI 코디네이터에서는 청년 정책, 민원 창구, 지역말, 생활 활동을 자연어로 질문할 수 있습니다. Python이 먼저 검증된 JSON 자료를 검색한 뒤 관련 자료만 AI에 전달합니다. 자료에 없는 내용은 추측하지 않고, 정책 자격을 확정하지 않으며, 긴급 상황은 109, 112, 119 안내를 우선하도록 설계했습니다.

## 슬라이드 7. 기술 구조

사용자 입력을 JavaScript가 검증하고 `fetch`로 `/api/recommend` 또는 `/api/chat`에 보냅니다. Vercel의 Python Function이 정책 규칙 판정이나 자료 검색을 수행하고 AI를 호출합니다. 결과는 JSON으로 돌아오며 JavaScript가 다시 화면에 표시합니다. HTML은 구조, CSS는 디자인, JavaScript는 동작, Python은 서버 처리를 담당합니다.

## 슬라이드 8. 오류와 개선

개발 과정에서 여러 실제 오류를 해결했습니다. 첫째, Vercel 프리셋이 Python으로 잡히고 `main` 브랜치가 운영 주소를 덮어써서 404가 발생했습니다. 프리셋을 `Other`로 바꾸고 과제 브랜치를 Production으로 지정했습니다.

둘째, 환경 변수 이름과 적용 범위가 달라 키를 인식하지 못했습니다. 셋째, 여러 환경 변수 문장을 Gemini 키 한 값에 붙여 넣어 요청 헤더가 깨졌습니다. 비밀값 정규화 로직을 추가해 해당 키 한 줄만 추출하도록 개선했습니다.

넷째, OpenAI API는 사용 한도 문제로 `RateLimitError`가 발생했습니다. 그래서 Gemini를 우선 사용하고 실패할 때 OpenAI를 대체 호출하도록 구조를 변경했습니다. 마지막으로 임시 진단 과정에서 비밀값이 노출될 가능성을 확인해 상세 진단 응답을 제거하고 키 패턴 검사를 추가했습니다.

## 슬라이드 9. 테스트와 반응형

운영 URL에서 총 17개 실행 테스트를 진행했고 17개 모두 통과했습니다. 맞춤 혜택 API는 세 번 연속 성공했고, 정책 24건을 정상 판정했습니다. 빈 입력, 500자 초과, 필수값 누락, 잘못된 나이도 정상 차단됐습니다. 데스크톱과 모바일 화면, AI 답변, 정책 결과, 오류 화면을 증빙으로 저장했고 응답 내 비밀값 노출은 0건이었습니다.

## 슬라이드 10. 결론

오이소창원 Lite는 기존 아이디어를 과제 기술 구조로 옮기는 데서 끝나지 않고, 실제 URL 배포, 외부 AI 연동, 오류 분석, 보안, 반복 테스트까지 완료한 결과물입니다. 다만 정책 정보는 바뀔 수 있으므로 최종 자격과 모집 일정은 공식 기관에서 다시 확인하도록 안내했습니다. 향후에는 정책 데이터 자동 갱신, 검색 동의어 확대, 실제 사용자 모바일 테스트를 추가할 수 있습니다.
