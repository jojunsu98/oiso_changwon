# 오이소창원 Lite 발표 대본

## 1. 제목

안녕하세요. 창원 전입 청년의 첫 180일을 돕는 AI 정착 코디네이터, 오이소창원 Lite를 소개하겠습니다.

## 2. 문제와 타겟

창원으로 이사 온 청년은 주거·취업·교통·복지 정보를 여러 기관에서 따로 찾아야 합니다. 정책을 발견해도 자신의 나이, 전입일, 재직 상태와 맞는지 판단하기 어렵고 신청 시점을 놓치기 쉽습니다. 주요 타겟은 창원 전입 또는 전입 예정 청년입니다.

## 3. 기존 서비스에서 Lite로

기존 오이소창원은 Streamlit 팀 프로젝트였습니다. 이번 개인 미션에서는 서비스 콘셉트와 검증 데이터는 유지하되, 순수 HTML·CSS·JavaScript와 Vercel Python Functions 구조로 다시 구현했습니다.

## 4. 주요 기능

웹페이지는 홈, 서비스, 맞춤 혜택, 생활 안내, AI 코디네이터, 안내의 여섯 섹션으로 구성했습니다. 맞춤 혜택에서는 여섯 가지 조건을 입력하면 정책 24건을 네 단계로 판정합니다.

## 5. 동작 구조

사용자 입력을 JavaScript가 검증하고 `fetch`로 Python API에 보냅니다. Python은 정책 규칙 판정 또는 검증 자료 검색을 수행한 뒤 AI를 호출합니다. 결과는 JSON으로 돌아오고 JavaScript가 화면에 표시합니다.

## 6. AI 기능

첫 번째 AI 기능은 정책 판정 결과를 짧은 정착 브리핑으로 설명합니다. 두 번째는 정책, 민원, 지역말, 생활 활동 질문에 답하는 AI 코디네이터입니다. 자료에 없는 내용은 추측하지 않도록 제한했습니다.

## 7. 배포와 보안

Vercel에 배포했고 실제 주소는 https://oiso-changwon-lite.vercel.app입니다. API 키는 Vercel 환경 변수로 관리하며 브라우저에는 전달하지 않습니다. 실명이나 전화번호도 입력받지 않습니다.

## 8. 오류 개선

개발 과정에서 잘못된 Vercel 프리셋, 브랜치 덮어쓰기, 환경 변수 범위와 이름 불일치, 여러 키가 한 값에 붙는 오류, OpenAI 사용 한도 문제를 겪었습니다. 프리셋과 배포 브랜치를 수정하고, 비밀값 정규화와 Gemini 우선·OpenAI 대체 구조를 추가했습니다.

## 9. 테스트

운영 URL에서 17개 실행 테스트를 모두 통과했습니다. 맞춤 혜택 API도 세 번 연속 성공했고, 빈 입력과 잘못된 나이, 긴 질문, 긴급 상황 처리도 정상 작동했습니다. 테스트 응답에서 비밀값 노출은 없었습니다.

## 10. 결론

오이소창원 Lite는 기존 아이디어를 과제 기술 구조로 옮기면서 실제 배포, 오류 분석, 보안, 반복 테스트까지 완료한 결과물입니다. 정책 정보는 변경될 수 있으므로 최종 자격은 공식 기관에서 다시 확인하도록 설계했습니다.
