## 1. 서비스 개요

- **서비스명:** 오이소창원 Lite
- **한 줄 설명:** 창원 전입 청년의 첫 180일 동안 놓치기 쉬운 혜택과 할 일을 내 조건으로 판정하고 일정과 다음 행동으로 정리하는 AI 정착 코디네이터
- **슬로건:** 창원에서 너의 내일을 응원해!
- **목적:** 창원으로 새로 전입했거나 전입을 준비하는 청년이 흩어진 정책·생활 정보를 직접 찾아 비교해야 하는 부담을 줄인다.
- **핵심 흐름:** 내 조건 → 판정 → 일정 → 안내
- **정보 원칙:** 정책 자격은 규칙으로 비교하고, AI는 검증 자료 범위에서 결과를 설명한다. 최종 자격을 AI가 확정하지 않는다.

## 2. 기존 오이소창원과의 관계

오이소창원 Lite는 새로운 콘셉트의 서비스가 아니다. 기존 팀 프로젝트 **「오이소창원 — AI 기반 창원 정착 지원 Agent」**의 목적·타겟·브랜드·정보 원칙·핵심 사용자 여정을 그대로 유지하고, 코디세이 개인 미션의 기술 요건에 맞춰 웹 구조를 다시 구현한 버전이다.

| 구분 | 기존 오이소창원 | 오이소창원 Lite |
|---|---|---|
| 서비스 목적 | 창원 전입 청년 정착 지원 | 동일 |
| 타겟 | 창원 전입·전입 예정 청년 | 동일 |
| 슬로건 | 창원에서 너의 내일을 응원해! | 동일 |
| 핵심 기능 | 맞춤 혜택·생활 일정·불편사항·지역말·Agent | 동일한 기능 축 유지 |
| 정책 판정 | 검증 DB + 규칙 판정 | 기존 규칙 모듈 재사용 |
| AI 원칙 | 검증 자료 기반, 추정 금지 | 동일 |
| 프론트엔드 | Streamlit | 순수 HTML/CSS/JavaScript |
| 백엔드 | Streamlit 내부 Python | Vercel Python Functions (`api/`) |
| 배포 | Streamlit Community Cloud | Vercel |

**Lite의 의미는 콘셉트 축소가 아니라 구현 범위의 경량화다.** 이메일 알림, 영구 상태 저장, 전체 리포트·캘린더 파일 생성처럼 운영 복잡도가 높은 부가 기능은 우선 제외하고, 과제의 핵심 학습 흐름인 사용자 입력 → JavaScript 요청 → Python API → AI 응답 → 화면 출력을 명확하게 구현한다.

## 3. 타겟 사용자

### 주요 사용자

- 창원으로 최근 전입한 만 19~39세 청년
- 창원 전입을 준비하며 정책과 생활 정보를 미리 확인하려는 청년
- 창원에서 주거·취업·교통·생활 불편·지역말 정보를 한곳에서 확인하려는 사람

### 대표 사용자 시나리오

1. 사용자가 만 나이, 전입일, 현재 하는 일, 창원 사업장 재직 여부, 전입 전 타지역 거주 기간, 차량 보유 여부를 입력한다.
2. Python 백엔드가 정책 24건을 기존 규칙 엔진으로 비교한다.
3. 결과를 `해당 가능`, `조건부 해당 가능`, `직접 확인`, `해당 없음`으로 구분한다.
4. AI가 규칙 판정 결과 중 우선 확인할 정책과 다음 행동을 짧게 설명한다.
5. 사용자가 추가 질문을 입력하면 AI 코디네이터가 정책·민원·지역말·생활 활동 자료를 검색해 근거 범위 안에서 답한다.

| 메뉴/섹션 | 목적 | 주요 내용 |
|---|---|---|
| 홈 | 서비스 가치 전달 | 슬로건, 첫 180일, 핵심 흐름, 시작 버튼 |
| 서비스 | 전체 콘셉트 설명 | 맞춤 혜택, 생활 일정, 불편사항, 지역말 |
| 맞춤 혜택 | 핵심 입력·결과 기능 | 사용자 조건 폼, 4단계 판정, AI 요약, 정책 카드 |
| 생활 안내 | 지역생활 연결 | 민원·상담 연락처, 지역말 예시 |
| AI 코디네이터 | 자유 질문 | 정책·민원·지역말·활동 자료 기반 답변 |
| 안내 | 신뢰·보안 설명 | 정보 원칙, 개인정보 원칙, 한계·면책 |

## 5. AI 기능 설계

### 기능 A. 맞춤 정착 브리핑

#### 입력

- 만 나이
- 창원 전입일
- 현재 하는 일
- 창원 사업장 재직 여부
- 전입 전 타지역 거주 기간
- 차량 보유 여부

#### 처리

1. 프론트엔드 JavaScript가 입력값을 JSON으로 구성한다.
2. `fetch('/api/recommend')`로 Python Function에 POST 요청한다.
3. 기존 `src/policy_matcher.py`가 정책 24건을 규칙으로 판정한다.
4. OpenAI API가 상위 판정 결과를 바탕으로 4~6문장 브리핑을 작성한다.
5. 브라우저가 AI 요약, 단계별 개수, 정책 카드를 화면에 표시한다.

#### 출력

- AI 정착 브리핑
- 4단계별 정책 개수
- 정책명, 판정 단계, 판정 이유
- 지원 내용, 확인·신청 방법
- 확인 일정과 공식 확인 경로

#### 가치

사용자가 정책 목록을 일일이 읽기 전에 본인 조건에서 먼저 확인할 항목과 다음 행동을 파악할 수 있다.

### 기능 B. 오이소창원 AI 코디네이터

#### 입력

최대 500자의 자연어 질문

예시:

- `창원으로 이사 온 직장인이 확인할 지원금이 있어?`
- `청년 월세 지원은 지금 신청할 수 있어?`
- `가로등이 고장 났는데 어디에 말해야 해?`
- `욕봤데이는 무슨 뜻이야?`

#### 처리

1. `fetch('/api/chat')`으로 질문과 선택적 사용자 조건을 전달한다.
2. Python이 정책·불편사항·지역말·생활 활동 JSON에서 관련 자료를 검색한다.
3. 검색 결과만 OpenAI API에 제공한다.
4. AI는 자료에 없는 내용을 추측하지 않고 답변한다.
5. 답변에 참고한 공식 경로 또는 자료명을 함께 표시한다.

#### 출력

- 질문에 대한 한국어 답변
- 다음 행동 또는 확인 방법
- 참고 자료명과 공식 링크

#### 가치

사용자는 서비스 메뉴를 모두 탐색하지 않고도 생활 언어로 필요한 정보를 찾을 수 있다.

## 6. 실패 처리 기준

| 상황 | 백엔드 처리 | 사용자 안내 |
|---|---|---|
| 필수 입력 누락 | HTTP 400 | `필수 항목을 모두 입력해 주세요.` |
| 잘못된 나이·날짜·선택값 | HTTP 400 | 잘못된 항목을 구체적으로 표시 |
| 질문 빈값 | HTTP 400 | `질문을 입력해 주세요.` |
| 질문 500자 초과 | HTTP 400 | 입력 길이 제한 안내 |
| OpenAI 키 미설정 | HTTP 503 또는 AI 요약 비활성 | Vercel 환경 변수 설정 필요 안내 |
| OpenAI API 오류 | HTTP 502 또는 규칙 결과 유지 | `잠시 후 다시 시도해 주세요.` |
| 응답 30~40초 초과 | JavaScript `AbortController`로 중단 | 응답 지연 안내 |
| 관련 검증 자료 없음 | 추정 답변 생성 안 함 | 질문 범위를 더 구체화하도록 안내 |
| 생명 위기·긴급 표현 | AI 호출 전에 고정 안전 경로 | 109·112·119 등 즉시 연락 안내 |

## 7. 기술 구조

```text
사용자
  ↓ 입력
index.html
  ↓ 이벤트 처리
js/app.js
  ↓ fetch('/api/recommend') / fetch('/api/chat')
Vercel Python Functions
  ├─ api/recommend.py
  │   ├─ 기존 정책 규칙 엔진
  │   └─ OpenAI 요약
  └─ api/chat.py
      ├─ 검증 JSON 검색
      └─ OpenAI 근거 기반 답변
  ↓ JSON 응답
JavaScript가 결과를 화면에 표시
```

- Vanilla JavaScript
- Python 3
- Vercel Python Functions
- OpenAI Responses API
- GitHub / GitHub Actions
- Vercel

## 10. 보안·운영 원칙

- `OPENAI_API_KEY`는 Vercel 환경 변수에만 저장한다.
- `.env.example`에는 예시 값만 기록하고 실제 키는 커밋하지 않는다.
- 브라우저 JavaScript에 API 키를 넣지 않는다.
- 서버 오류 응답에 키·내부 경로·전체 예외 내용을 노출하지 않는다.
- 입력 크기와 질문 길이를 제한한다.
- 실명·전화번호·주민등록번호를 입력받지 않는다.
- 정책·행사 정보에는 확인일과 공식 확인 경로를 표시한다.

## 12. 출처·기여 표기

기존 오이소창원은 조준수·이혜경·이미영이 참여한 팀 프로젝트다. Lite 버전의 제출 문서에서는 팀 프로젝트 전체를 개인 단독 결과물로 표현하지 않는다.

표기 문구:

> 본 서비스는 기존 팀 프로젝트 「오이소창원」의 공동 기획·검증 데이터·브랜드 자산을 기반으로 하며, 조준수가 코디세이 개인 미션에서 순수 HTML/CSS/JavaScript 프론트엔드와 Vercel Python Functions 구조로 재구현한 학습용 Lite 버전입니다.
